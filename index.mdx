Prophecy lets teams build production-grade data pipelines using SQL, PySpark, and natural language. You describe what you want to do with your data, and the Prophecy Agent helps you generate, modify, and understand pipelines directly in your project.

The Agent works within your active environment—inspecting metadata, retrieving sample data where permitted, and translating your intent into concrete pipeline changes that you can inspect and validate. From initial exploration to production deployment, Prophecy supports the full lifecycle of data work while keeping everything transparent and editable.

Projects are built in shared environments where analysts and engineers collaborate across pipelines, analyses, and workflows. Each project is backed by Git and deployed to governed execution environments called fabrics.

## Why use Prophecy

Prophecy makes it easier to go from an idea to production-ready data pipelines.

**Build with natural language**: Describe what you want to do, and the Agent generates or updates pipelines directly in your project. [Learn about the Agent](/data-analysis/ai/agent).

**Faster iteration**: Move from idea to working pipelines without navigating multiple tools or writing everything from scratch. [See our Quickstart page](/data-analysis/getting-started/quick-start).

**Designed for analysts**: Work in SQL while still building production-grade pipelines and workflows. [Learn about developing pipelines](/data-analysis/development/pipelines/data-analysis-pipelines).

**Production-ready by default**: Deploy pipelines with built-in scheduling, observability, and environment separation. [Learn about publishing pipelines](/data-analysis/production/publication).

## What you can build with Prophecy

Prophecy supports a broad range of data workflows, from exploration to production systems.

**AI-generated pipelines**: Use natural language to create and modify pipelines directly in your project with the [Prophecy Agent](/data-analysis/ai/agent).

**Data pipelines**: Transform, join, and prepare data using SQL or PySpark with visual or code-based development [pipelines](/data-analysis/development/pipelines).

**Orchestrated workflows**: Build multi-step pipelines with dependencies, conditional logic, and parameterized execution using [pipeline gems](/data-analysis/production/scheduling/pipeline-trigger-gem).

**Reusable data products**: Create pipelines that can be [scheduled](/data-analysis/production/scheduling/scheduling), [reused](/data-analysis/development/versioning/clone-projects), and [shared](/data-analysis/collaboration/project-sharing) across [teams](data-analysis/administration/management/teams/teams).

**Analytics-ready datasets**: Produce clean, reliable datasets for [BI tools and downstream consumption](/data-analysis/gems/source-target).
