---
title: Source And Target
description: Set of gems related to reading and writing data
---

The Source and Target gems to help you work with various file-based formats, connect to a warehouse-style data source, and work with various table-based formats.

## File

You can use the Source and Target gems to help you work with following file-based formats:

| Formats                                 |                               |                                 |
| --------------------------------------- | ----------------------------- | ------------------------------- |
| [Avro](/data-engineering/gems/source-target/file/avro)                 | [JSON](/data-engineering/gems/source-target/file/json)       | [Seed](/data-engineering/gems/source-target/file/seed)         |
| [CSV](/data-engineering/gems/source-target/file/csv)                   | [Kafka](/data-engineering/gems/source-target/file/kafka-stream)     | [Text](/data-engineering/gems/source-target/file/text)         |
| [Delta](/data-engineering/gems/source-target/file/delta)               | [ORC](/data-engineering/gems/source-target/file/orc)         | [XLSX (Excel)](/data-engineering/gems/source-target/file/xlsx) |
| [Fixed Format](/data-engineering/gems/source-target/file/fixed-format) | [Parquet](/data-engineering/gems/source-target/file/parquet) | [XML](/data-engineering/gems/source-target/file/xml)           |

### Synthetic data generator

You can generate synthetic data with [the data generator file type](/data-engineering/gems/source-target/file/synthetic-data-generator). It allows you to specify the data type of each column and populates them with randomly generated data. You can also specify additional requirements such as the boundaries for each row, and the percentage of rows that must have null values.

## Lookup

[Lookup](/data-engineering/gems/source-target/lookup) is a special component that allows you to broadcast any data and use it anywhere in your pipeline at a later time.
