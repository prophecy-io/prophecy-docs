---
title: Configure Azure AI Foundry (Claude) for Prophecy
description: Set up Azure AI Foundry as the LLM provider for Claude in Prophecy using Transform Agent configuration.
---

You can configure Prophecy to use Claude models through Azure AI Foundry by updating the Transform Agent configuration in Admin settings. This setup allows Prophecy to route LLM requests through your Azure-managed deployment instead of the public Anthropic API.

This configuration is useful when you want centralized credential management, controlled deployments, or enterprise governance through Azure AI Foundry.

## Navigate to settings

Go to the following path in the application:

```text
Config → Admin → Copilot Settings
```

Locate **AI Model Provider Credentials** and edit the **Transform Agent JSON**.

## Configure Azure AI Foundry

Replace the existing configuration with the following:

```json
{
  "transform_agent": {
    "foundry_config": {
      "use_foundry": "true",
      "foundry_api_key": "YOUR_API_KEY",
      "foundry_base_url": "YOUR_BASE_URL",
      "foundry_model": "claude-opus-4-5"
    }
  }
}
```

## Configuration parameters

| Parameter            | Description                        |
| -------------------- | ---------------------------------- |
| **foundry_api_key**  | Your Azure AI Foundry API key      |
| **foundry_base_url** | Your Azure AI Foundry endpoint URL |
| **foundry_model**    | The deployed Claude model name     |

## Important

- Remove `/v1/messages` from the base URL provided by Azure AI Foundry.
- The model name must match the deployment name in Azure Foundry.

## Default configuration (Anthropic API)

If you use the public Anthropic API instead of Azure AI Foundry, configure the Transform Agent as follows:

```json
{
  "transform_agent": {
    "anthropic_key": "<anthropic API key>"
  }
}
```

## How it works

Prophecy uses the Transform Agent configuration to determine which LLM provider to call. Adding a `foundry_config` block enables Azure AI Foundry as the provider.

Only one provider can be configured at a time, either Anthropic or Azure AI Foundry.
