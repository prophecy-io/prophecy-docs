The **Observability** interface in Prophecy lets you monitor your deployed projects, review scheduled pipelines, and audit run history. You'll be able to view all projects and pipelines that your teams own.

To access, click **Observability** (the line graph icon) in the left sidebar.

## Deployed Projects

The **Deployed Projects** tab in the Observability interface shows all projects that have been [published](/data-analysis/development/versioning/version-control) to Prophecy fabrics. It lets you view details on release versions and recent execution status at the project level.

For each project deployment, Prophecy provides the following information.

| Column              | Description                                                                       |
| ------------------- | --------------------------------------------------------------------------------- |
| **Project**         | Name of the deployed project. Click the name to navigate to the project metadata. |
| **Fabric**          | Fabric associated with the project deployment.                                    |
| **Release Version** | Version number of the deployed project release.                                   |
| **Published**       | Time since the project was last published.                                        |
| **Last Run**        | Time since the most recent pipeline execution in the project.                     |
| **Last Run Status** | Success or failure of the last run.                                               |

Use the following filters to narrow the results:

| Field              | Description                                                           |
| ------------------ | --------------------------------------------------------------------- |
| **Search project** | Search for a project by name.                                         |
| **Fabric**         | Filter results by the fabric (such as `AnalystDBX`, `devDatabricks`). |

<Info>
  When a project is published to multiple fabrics, Prophecy creates an individual project deployment for
  each fabric. You will see all of these deployments in the Deployed Projects page. You cannot
  revert or delete a project deployment.
</Info>

## Scheduled Pipelines

The **Scheduled Pipelines** tab in the Observability interface displays all pipelines configured with a schedule across environments. It provides details on pipeline execution frequency and recent run outcomes. Use this page to verify that pipelines are scheduled correctly and to identify patterns of success or failure.

For each scheduled pipeline, Prophecy provides the following information.

| Column          | Description                                                                                           |
| --------------- | ----------------------------------------------------------------------------------------------------- |
| **Pipeline**    | Name of the pipeline. Click to view the pipeline in the project editor.                               |
| **Schedule Name** | Name of the schedule.                                                                               |
| **Fabric**      | Fabric where the pipeline is deployed.                                                                |
| **Project**     | Project that contains the pipeline. Click the name to open the project.                               |
| **Triggers**    | Type of trigger for the schedule. Schedules can include multiple triggers.                            |
| **Concurrency Policy** | [Concurrency policy](/data-analysis/production/scheduling/schedule-setup#set-a-concurrency-policy) of the schedule: Queue, Skip, or Cancel. |
| **Last Trigger Status** | What happened the last time the schedule came due: **Ran** or **Skipped**. A time slot is skipped when the schedule uses the Skip concurrency policy and the previous run is still in progress. |
| **Last Trigger Time** | When the schedule last came due.                                                                    |
| **Last 5 runs** | Status of the 5 most recent completed runs. To find the history of all pipeline runs, open the Run History tab. |

<Info>
  You may see multiple rows for the same pipeline if the parent project is deployed to multiple
  fabrics.
</Info>

Use the following filters to narrow the results:

| Field               | Description                                                 |
| ------------------- | ----------------------------------------------------------- |
| **Search pipeline** | Search by pipeline name.                                    |
| **Fabric**          | Filter by fabric.                                           |
| **Project**         | Filter by the project that contains the scheduled pipeline. |

## Run History

Use the **Run History** tab in the Observability interface to view and analyze recent pipeline runs across all fabrics and projects. This page provides detailed metadata for each run, including its type, duration, status, and execution context.

You can also use Run History to open **historical runtime logs** and inspect previous pipeline executions in Historical Mode.

Use the following filters to narrow the results.

| Field          | Description                                                                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date Range** | Select a date range to limit results to runs that started in that window.                                                                                                             |
| **Fabric**     | Filter by fabric used to run the pipeline.                                                                                                                                            |
| **Project**    | Filter by the name of the project that contains the pipeline.                                                                                                                         |
| **Run Type**   | Select one or more run types to include. Supported values include:<ul><li>Scheduled</li><li>Pipeline Run</li><li>App Run</li><li>Scheduled App Run</li><li>API Pipeline Run</li></ul> |

For each historical pipeline run, Prophecy provides the following information.

| Column         | Description                                                                                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ID**         | Unique pipeline run ID. If the ID is truncated, hover over it to view the full value. <br />You can reference this value in the [Trigger Pipeline API](/api-reference/pipelines/trigger-pipeline-run).                  |
| **Fabric**     | Name of the fabric used to execute the pipeline run.                                                                                                                                                                     |
| **Pipeline**   | Name of the pipeline that was executed. Click the name to open the pipeline in the project editor.                                                                                                                       |
| **Project**    | Name of the project containing the pipeline. Click the name to open the project.                                                                                                                                         |
| **Run Type**   | How the run was triggered. <br />This includes interactive runs, pipeline schedules, APIs, and analysis runs. <br />Any scheduled runs include additional information about the schedule that triggered the run.        |
| **Start Time** | Timestamp when the run started.                                                                                                                                                                                          |
| **End Time**   | Timestamp when the run completed.                                                                                                                                                                                        |
| **Duration**   | Elapsed time of the run.                                                                                                                                                                                                 |
| **Logs**       | Click **See logs** to open historical runtime logs and the associated pipeline snapshot in Historical Mode. Shows **No logs available** when logs aren't available, such as for analysis runs and runs that are still in progress. |
| **Status**     | Status of the run. See [Run statuses](#run-statuses). <br />For failed, warning, and cancelled runs, hover over the status to see the message. |

To see who or what triggered a run, click the **Run details** icon at the end of the row. See [View run details](#view-run-details).

### Run statuses

| Status         | Description                                                                                     |
| -------------- | ----------------------------------------------------------------------------------------------- |
| **Queued**     | The run is waiting to start.                                                                    |
| **Running**    | The run is in progress.                                                                         |
| **Cancelling** | Prophecy is stopping the run.                                                                   |
| **Success**    | The run finished successfully.                                                                  |
| **Warning**    | The run finished with warnings.                                                                 |
| **Failed**     | The run failed.                                                                                 |
| **Cancelled**  | The run was stopped before it finished, by a user, a parent run, or a schedule's concurrency policy. |
| **Skipped**    | The run didn't execute.                                                                         |

### Stop a run

To stop a run that's in progress:

1. In the **Status** column of the run, click the **Stop run** icon.
1. Click **Stop run** to confirm.

Prophecy discards any work in progress and marks the run as **Cancelled**. If the run finishes before Prophecy can stop it, Prophecy tells you that the run already finished.

### Restart a scheduled run

You can restart a scheduled run that failed, finished with warnings, or was cancelled. The restart uses the schedule's current version and parameters.

To restart a run:

1. In the **Status** column of the run, click the **Restart run** icon.
1. Click **Restart run** to confirm.

The restart appears in Run History as a new attempt of the original run. You can only restart the latest attempt.

### View run details

Click the **Run details** icon at the end of a row to open the run details panel. The panel shows the run ID, which you can copy, and the run status. It also includes the following sections.

| Section      | Description |
| ------------ | ----------- |
| Trigger Info | What started the run: **User**, **Schedule**, **API**, **CLI**, or **Parent run**. For runs that a user started, the section shows the user's name and email. For related runs, it links to the **Parent Run ID**, the run that this run is a **Restart Of**, and the **Root Run ID**. |
| Cancel Info  | For cancelled runs, what stopped the run: **User**, **Schedule policy**, or **Parent run**. |

Click a linked run ID to open the details of that run. Click the back arrow to return to the previous run.

The **Run details** icon doesn't appear for older runs that don't have this information.

## Open historical runtime logs

You can inspect completed pipeline executions directly from the Run History table.

To open historical runtime logs:

1. Open the **Run History** tab and locate the run you want to inspect.
1. In the **Logs** column, click **See logs**.

![Open historical runtime logs](/data-analysis/development/runs/img/historical-logs.png)

Prophecy opens the selected pipeline in **Historical Mode**, restoring:

- Runtime logs for the selected execution
- The historical pipeline snapshot
- Component execution statuses and progress information

In Historical Mode, the pipeline canvas becomes read-only so you can safely review the historical execution context without modifying the current pipeline version.

<Info>
  Historical runtime logs and pipeline snapshots are retained for a limited period of time and may
  not be available for every historical run.
</Info>

For more information about runtime logs, Historical Mode, and pipeline snapshots, see [Runtime logs](/data-analysis/development/runs/runtime-logs).
