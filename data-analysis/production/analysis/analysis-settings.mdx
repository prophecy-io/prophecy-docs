Analysis settings control how your analysis behaves during development and runtime.

## Choose Parameter Set

To change the [parameter set](/data-analysis/development/parameters/parameter-sets) for an existing app:

1. Open the project that includes the analysis.
1. Click on the analysis in the project sidebar.
1. Click the settings icon or open **App Settings**.
1. Find the **Choose Parameter Set** dropdown.
1. Select the parameter set you want to use.
1. Click **Save**.

The selected parameter set applies to all app runs by default unless the end user provides their own values. If you don't define a parameter set for an app, the active parameter set is used.
