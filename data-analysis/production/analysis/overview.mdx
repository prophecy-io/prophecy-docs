When you build a pipeline for data analysis, you want to end up with consumable insights powered by your data. Analysis dashboards are the quick way to get from data to insights: just ask the Prophecy Agent to build one for you.

**For analysts building insights**: Get from raw data to shareable analysis in minutes. Use the Prophecy Agent to generate both the pipeline and dashboard together—no need to build data transformations by hand or export to separate BI tools for basic visualizations.

**For teams consuming insights**: Eliminate the bottleneck between data engineering and business users. Instead of creating duplicate pipelines or waiting for engineers to modify code, teams can reuse pipelines across different scenarios, reduce errors through built-in validation, and collaborate with standardized processes.

## Use cases

Analysis dashboards can be static (always showing results from the same data) or interactive (showing results based on user input). We'll explore both types and explain use cases for each.

## Static dashboards

Static dashboards display results from pipeline runs without requiring user input. They're perfect when you want to:

- Share a specific analysis or report with stakeholders.
- Preview pipeline outputs before publishing to BI tools.
- Schedule regular reports with different parameter configurations.

More specifically, you can:

- Preview and download pipeline output data in tabular format.
- Visualize intermediate and output data via charts and graphs.

## Interactive dashboards

Interactive dashboards let users customize inputs and run pipelines on demand. They're ideal when you want to:

- Eliminate the bottleneck between data engineering and business users.
- Enable team members to answer their own questions without writing code.
- Provide guardrails that guide users toward correct, tested execution paths.

How does it do so? You can:

- Upload custom data to replace pipeline input sources.
- Set pipeline parameters (dates, thresholds, regions) through simple form fields.
- Save personal configurations while maintaining a shared, standardized pipeline.
