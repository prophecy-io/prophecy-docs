This page describes the **Excel-specific properties** that appear in the **Properties** tab of Source and Target gems. These settings are the same for Excel files regardless of which connection type is configured in the gem (for example, S3, SFTP, or SharePoint).

If you need details on configuring a Source or Target gem end to end (including all tabs such as **Location**), see the documentation for the specific file storage connection.

<Info>
  You can also use the [upload file](/data-analysis/gems/source-target/table/upload-files) feature
  to use Excel files. These will be stored in the SQL warehouse configured in your fabric.
</Info>

## Properties

### Source properties

The following properties are available for the Excel Source gem.

| Property                      | Description                                                                                                                               | Default                |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| Description                   | Description of the table.                                                                                                                 | None                   |
| Header                        | Whether the first row is the column header.                                                                                               | True                   |
| Allow Undefined Rows          | Whether to permit rows with all values undefined (null or empty).                                                                         | True                   |
| Allow Incomplete Rows         | Whether to permit rows with missing values for some columns.                                                                              | True                   |
| Ignore Cell Formatting        | Whether to apply the number format for the cell value or get the raw value.                                                               | True                   |
| Sheet Reading method          | Whether to read one sheet of data or union the data from multiple sheets into one table. Learn more in [Reading sheets](#reading-sheets). | Read single sheet data |

| Skip reading top n rows | Number of rows to skip at the top of each sheet. If **Header** is enabled, the first row after the skipped rows is the header. Otherwise, it's the first data row. Can't be used with **Enter Cell Range**. | `0` |
| Default column prefix | Prefix for generated column names when **Header** is disabled or a header cell is empty. Prophecy appends the column index to the prefix. | `Column-` |
| Allow reading rows with all column cells as empty | Whether to keep rows in which every cell is empty. Empty rows at the end of a sheet are always dropped. | False |

| Record ID Column Name | Name of the record ID column. Appears only when **Append record id column to the output schema** is enabled. | `RecordId` |

### Reading sheets

Depending on the **Sheet Reading method** you choose, you will need to provide additional details.

#### Read single sheet data

For this option, Prophecy only reads one sheet of the Excel file.

| Additional property | Description                                                                                                                                        |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sheet Name          | Provide the name of the sheet to read. If the name you provide does not match the name of an existing sheet in the file, the gem will fail to run. |

#### Read union of multiple sheet data

For this option, Prophecy reads the data from each of the sheets that you specify. Then, the data is unioned into one output table.

| Additional property      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sheet Filter Condition   | Choose how you define the set of sheets to read. <ul><li><strong>Sheet name prefix equals</strong>: Read sheets whose names start with the provided value.</li><li><strong>Sheet name suffix equals</strong>: Read sheets whose names end with the provided value.</li><li><strong>Sheet name contains value</strong>: Read sheets whose names contain the provided substring.</li><li><strong>Sheet name is in below list (comma separated)</strong>: Read sheets whose names exactly match any comma-separated value provided in <em>Filter Value</em>.</li></ul> |
| Filter Value             | Provide the value used to evaluate the filter condition.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

<Info>The union operation will only succeed if each sheet has the same schema.</Info>

### Excel output mode

The **Excel Output Mode** setting appears in the **Location** tab of the Target gem when the format type is `xlsx`. It controls whether the gem creates a new workbook or writes into an existing one.

| Mode                                    | Behavior                                                                                                                                                                                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Create a new Excel file                 | Writes a new workbook to the **Target file path**. Any existing file at that path is replaced in full, including its other sheets. This is the default.                                                                                                                         |
| Create a new Excel file from a template | Builds a new workbook from the file in **Template file path** and writes it to the **Target file path**. The template's layout and other content are kept in the output, and the template file itself is not changed. Any existing file at the target path is replaced in full. |
| Update an existing Excel file           | Opens the workbook at **Base file path** and writes only the selected sheet. All other sheets and their positions are kept. The sheet or the file is created if it does not exist.                                                                                              |

<Note>
  **Dynamic data write to multiple files as per file column name** is not available when updating an
  existing Excel file.
</Note>

### Write to multiple files

When **Sheet Write method** is set to **Dynamic data write to multiple files as per file column name**, the gem writes one Excel file for each unique value in the **File Column Name** column. Each file is named `<prefix><value>.xlsx`, where `<prefix>` is the **File Prefix for multi file write** value. Rows are written to the sheet named in **Output File Sheet Name**.

Where the files are written depends on the file path configured in the gem:

- If the path ends with `/` or has no file extension, it is treated as a folder, and the files are written inside it. For example, with the prefix `File_`, the path `exports/orders/` produces `exports/orders/File_US.xlsx`, `exports/orders/File_EU.xlsx`, and so on.
- If the path includes a file name, such as `exports/orders.xlsx`, the files are written to that file's parent folder. The file name itself is ignored.

Rows with a null or blank value in the file column are written to `<prefix>unknown.xlsx`.
