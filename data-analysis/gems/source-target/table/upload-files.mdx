You can upload a file to your fabric's DataBox directly from the visual canvas, then add it to your pipeline as a source. This gives you a quick way to bring a local file into a project without first setting up a connection.

<Note>The DataBox is available only when a cluster admin has enabled it for your fabric.</Note>

<Warning>
  Uploads are not currently scanned for viruses, zip bombs, or disguised file types.
</Warning>

## Upload a file

1. Open a pipeline.
1. In the canvas, open the **Source/Target** menu and select **Upload Files**.
1. Choose the file you want to upload.

<Note>Dragging a file directly onto the canvas does the same thing.</Note>

A confirmation showing the file name appears once the upload completes. The file is stored in the fabric's [Prophecy File System](/data-analysis/environment/connections/prophecy-file-system), inside a **projects** folder named for your project.

<Note>Uploads are limited to 20 files and 2 GB per batch.</Note>

## Use the uploaded file in your pipeline

From the Environment browser, use the three-dot menu next to the file to:

- Select **Add as Source** to add the file to your pipeline as a [Source gem](/data-analysis/gems/source-target/source-target), with the connection already set to **Prophecy File System**.
- Preview the file.
- Delete the file.
