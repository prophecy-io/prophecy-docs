Prophecy's Agent lets you build and modify pipelines, analyses, and other project entities using natural language.

## What you can do with the Agent

You can use the Agent to:

- create or update entities.
- ask questions about your project.
- reference existing project entities.
- upload files for context.
- review AI-generated changes.
- manage multiple chat sessions.

## Send prompts

Use the message box at the bottom of the chat panel to send prompts to the Agent.

You can ask the Agent to:

- create new transformations or analyses.

- modify existing entities.

- explain project logic.

- troubleshoot pipelines.

- answer questions about project assets.

Example prompts:

- `Create a new transformation that filters failed orders`

- `Add a join between customer and transaction tables`

- `Explain how this model calculates churn risk`

## Provide context to the Agent

You can provide additional context to help the Agent understand your project and requests.

### Upload files

Use the attachment icon in the message box to upload files.

Uploaded files can help the Agent:

- understand schemas.

- review requirements.

- reference specifications.

- analyze supporting documents.

For more information, see [Upload files](/data-analysis/ai/agent/chat/upload-files).

### Reference project entities

Use `@` mentions to reference project entities directly in chat.

You can reference:

- pipelines.

- models.

- analyses.

- project assets.

Referencing entities gives the Agent additional project context and helps it understand which assets you want to modify or discuss.

For more information, see [Reference project entities](/data-analysis/ai/agent/chat/mentions).

## Manage conversations

AI chat supports multiple conversations within the same project. The chat panel appears on the left side of the project, below the project name. To hide it, turn off **Show chat** in [development settings](/data-analysis/development/studio/development-settings). When the chat is hidden, the project browser moves to the left.

### View chat history

Click the **Chat History** icon above the chat panel, next to the project name, to view previous conversations.

The currently active chat is labeled **Current**.

From chat history, you can:

- reopen previous chats.
- rename chats.
- delete chats.
- [copy session details](/data-analysis/ai/agent/chat/export).

The rename, copy, and delete icons appear when you hover over a chat.

### Start a new chat

Click the **Add New Chat** icon above the chat panel to begin a separate conversation. This icon is unavailable while the current chat is empty.

Starting a new chat does not remove existing project entities.

When starting a new chat, the Agent may reference existing project entities and suggest:

- updating existing transformations.
- creating new analyses.
- continuing work within the current project.

### Rename chats

To rename a chat:

1. Open chat history.
2. Hover over the chat and click the **Rename conversation** (pencil) icon.
3. Enter a new name, then press Enter or click outside the field to save it.

Use descriptive names to organize project conversations.

### Delete chats

Delete chats from the chat history panel.

Deleting a chat removes that conversation from your project history.

Deleting the current chat automatically opens a new chat session.

### Copy session details

In chat history, use the copy button to copy information about a conversation. The button's tooltip reads **Copy Session Details**.

This can help when:

- sharing troubleshooting context.

- collaborating with teammates.

- reporting issues.

- documenting AI-generated changes.

For more information, see [Copy chat session details](/data-analysis/ai/agent/chat/export).

## Review AI-generated changes

The Agent can modify project entities directly from chat interactions.

### Review modified entities

After the Agent makes changes, the chat displays a review area showing which entities were modified.

Review changes carefully before continuing work.

Modified entities may include:

- pipelines.
- models.
- analyses.
- transformations.

### Undo or roll back AI changes

Responses that changed your project include an action below the response that reverts those changes:

- **Undo** appears on the most recent response with changes. It reverts the changes from that response.
- **Rollback** appears on older responses with changes. It restores the project to its state before that response and reverts the changes from every later response.

When you click **Undo** or **Rollback**, Prophecy asks you to confirm. Click **Undo changes** or **Rollback changes** to continue. You can't undo or roll back changes when the project is in read-only mode.

## Interactive clarification questions in Prophecy Agent

The Agent may pause during generation to ask for additional input before continuing.

When the Agent needs clarification, it displays one or more questions directly in the chat along with answer options. Select an answer, or type your own in the **Other** field, and click **Submit**. If there are several questions, use **Prev** and **Next** to move between them. The Agent then continues using your answers. This lets the Agent gather missing information and resolve ambiguities instead of making assumptions or failing when it needs more context.

Click **Skip** if you don't want to answer. The Agent continues with the available context.

## Approve Agent writes

The Agent requests approval in the chat before it:

- Runs a pipeline that writes data to your warehouse. The prompt names the pipeline and warns that the operation will write data to your warehouse, may overwrite existing data, and can't be reverted.
- Runs a query that modifies your warehouse, such as a statement that creates, changes, or deletes data. The prompt shows the query and warns that it can't be reverted.

You can choose:

* **Allow once** to approve the current action.
* **Always allow** to approve the current action and skip the prompt for later actions of the same kind in the current session.
* **Deny** to prevent the action.

**Always allow** applies only to the current session. If you refresh the page, the Agent prompts for approval again.

This confirmation step helps prevent unintended data modifications while giving you control over Agent-initiated writes. The Agent doesn't ask for approval before it edits project files, because you can [undo those changes](#undo-or-roll-back-ai-changes).

## Continue work across chats

Chats are project-aware and can reference existing entities in your project.

Even when starting a new chat, the Agent can:

- detect existing project assets

- help continue existing workflows

- create new entities related to previous work

This allows you to organize conversations by task while continuing work within the same project.

## Tips for working with AI chat

- Use descriptive chat names for larger projects.
- Reference entities with `@` mentions when modifying existing assets.
- Upload supporting files to provide additional context.
- Review AI-generated changes before continuing work.
- Use separate chats for unrelated workflows or experiments.
