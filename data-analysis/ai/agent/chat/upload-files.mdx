---
title: Upload files
description: Upload files to the Agent chat for use in your project
---

When you drag a file into the Agent chat, or drop it directly onto the pipeline canvas, Prophecy uploads it to your fabric's Databox (the [Prophecy File System](/data-analysis/environment/connections/prophecy-file-system)). A confirmation showing the file name appears once the upload completes.

<Note>The Databox is available only when a cluster admin has enabled it for your fabric.</Note>

<Warning>
  Uploads are not currently scanned for viruses, zip bombs, or disguised file types.
</Warning>

## Upload a file

1. Drag a file into the Agent chat, or drop it directly onto the pipeline canvas.
1. Wait for the confirmation showing the file name.

<Note>Uploads are limited to 20 files and 2 GB per batch.</Note>

The file appears in the Environment browser under the **Prophecy File System** connection, inside a **projects** folder named for your project.

## Use an uploaded file

From the Environment browser, use the three-dot menu next to the file to:

- Select **Add as Source** to add the file to your pipeline as a [Source gem](/data-analysis/gems/source-target/source-target).
- Preview the file.
- Delete the file.

<Note>
  Before the Agent deletes a file on its own, it asks for your confirmation.
</Note>
