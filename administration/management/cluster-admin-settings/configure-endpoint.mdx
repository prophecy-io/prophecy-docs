title: Configure Anthropic endpoint for Prophecy
description: Set up LLM provider for Anthropic Claude in Prophecy.

Prophecy Agents use Anthropic Claude models. You can access Claude directly through Anthropic or through Azure AI Foundry. You choose the provider in the `transform_agent` block of your Copilot settings.

<Callout icon="/images/icon.png" color="#FFC107">
  Applicable to the [Express and Enterprise Editions](/administration/platform/editions) only.
</Callout>

## Navigate to settings

1. Log in to Prophecy as an administrator.
2. Go to **Settings > Admin > Copilot Settings**.
3. Open the **AI Model Providers Creds** subtab.
4. Click **Edit**, add or update the `transform_agent` block in the JSON, and click **Save**.

The `transform_agent` block sits alongside any Copilot provider credentials in the same JSON. For details, see [Copilot settings](/administration/management/cluster-admin-settings/copilot-settings).

## Configure Anthropic (public API)

Use this option to connect directly to Anthropic using an API key from the Anthropic Console.

Apply the following configuration:

```json
{
  "transform_agent": {
    "anthropic_key": "<anthropic API key>"
  }
}
```

This configuration sends requests directly to Anthropic's public API using your provided API key.

## Configure Azure AI Foundry

Use this option to route Claude requests through your Azure AI Foundry deployment.

Apply the following configuration:

```json
{
  "transform_agent": {
    "foundry_config": {
      "use_foundry": "true",
      "foundry_api_key": "YOUR_API_KEY",
      "foundry_base_url": "YOUR_BASE_URL",
      "foundry_model": "claude-opus-4-5"
    }
  }
}
```

### Configuration parameters

| Parameter            | Description                                                     |
| -------------------- | --------------------------------------------------------------- |
| **use_foundry**      | Set to `true` to use Azure AI Foundry.                          |
| **foundry_api_key**  | Your Azure AI Foundry API key. Required.                        |
| **foundry_base_url** | Your Azure AI Foundry endpoint URL. Required.                   |
| **foundry_model**    | The deployed Claude model name.                                 |

When you configure Azure AI Foundry:

- Remove `/v1/messages` from the base URL provided by Azure AI Foundry.
- The model name must match the deployment name in Azure AI Foundry.

## Limit the cost of a chat

You can cap the total model cost of a single agent chat with `session_cost_limit_usd`:

```json
{
  "transform_agent": {
    "anthropic_key": "<anthropic API key>",
    "session_cost_limit_usd": 20
  }
}
```

When a chat reaches the limit, the agent stops responding in that chat and asks the user to start a new chat. If you leave out the setting or set it to `0`, chats have no cost limit.

## How it works

Prophecy uses the `transform_agent` configuration to determine which provider handles Claude requests:

- If `use_foundry` is `true`, Prophecy uses Azure AI Foundry.
- Otherwise, Prophecy uses the Anthropic public API with `anthropic_key`.
