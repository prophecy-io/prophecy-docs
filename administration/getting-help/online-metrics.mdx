The Online Metrics dashboard provides visibility into the performance and health of your Prophecy pipelines and AI interactions.

Use the dashboard to:

- Monitor pipeline compilation performance over time.
- Track AI Copilot usage and response quality.
- Identify trends and measure progress against targets.

## Understanding metrics

Each metric is displayed with a current value, trend indicator, and target threshold:

| Column | Description |
|--------|-------------|
| Current | The most recent measured value. |
| Trend | Whether the metric is improving (↑), stable (→), or declining (↓). |
| Target | The threshold Prophecy recommends as a healthy baseline. |
