---
openapi: put /api/fabrics/{fabricId}/credentials
---

Use this endpoint to rotate the password of a Snowflake fabric without opening the fabric in Prophecy. It works only for Snowflake fabrics whose warehouse connection uses **Username and Password** authentication and stores the password as a Prophecy secret.

<Note>
  Each request is recorded in the [audit log](/administration/management/audit-logs) as a `FABRIC_CREDENTIALS_UPDATE` event. The audit event records the username and role, but never the password.
</Note>
