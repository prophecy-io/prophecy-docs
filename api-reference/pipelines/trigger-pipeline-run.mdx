## Requirements

To run the API, the target pipeline must run on a [Prophecy fabric](/data-analysis/environment/fabrics/prophecy-fabrics). The pipeline does not need to be deployed.

## Choose what to run

Choose what to run by adding one of these fields to the request:

| To run                                                                                   | Add to the request          |
| ---------------------------------------------------------------------------------------- | --------------------------- |
| The project as it is now in Prophecy, including saved changes that are not committed yet | Nothing (default)           |
| A specific branch                                                                        | `"branch": "<BRANCH_NAME>"` |
| A published release                                                                      | `"version": "<VERSION>"`    |

<Warning>
  If `version` does not match a release exactly, Prophecy runs the current working state instead and
  still reports success. Copy the version from the [list releases
  query](/api-reference/projects/list-releases).
</Warning>

`success` in the response means the run was accepted, not that it finished. Check progress with the [get pipeline run status API](/api-reference/pipelines/get-pipeline-run-status), and stop a run with the [cancel pipeline run API](/api-reference/pipelines/cancel-pipeline-run).

## Parameters

Parameters work the same way for all three run types.

- `parameters` overrides pipeline parameters. Each key must be one of the pipeline's own parameters; otherwise, the request returns `Invalid config override`.
- `projectParameterSet` selects which project [parameter set](/data-analysis/development/parameters/parameter-sets) the run uses.
- `projectParameters` overrides individual project parameters. Each key must be one of the project's parameters; otherwise, the request returns `Invalid project parameter override`. These values take precedence over the selected parameter set.

For example, to run with the `prod` parameter set but override one project parameter:

```json
{
  "fabricId": 1234,
  "projectId": "5678",
  "pipelineName": "load_orders",
  "projectParameterSet": "prod",
  "projectParameters": {"region": "EU"}
}
```

Overrides apply only to this run. To change a project's or pipeline's saved parameter values, use the [update project parameters](/api-reference/projects/update-project-parameters) or [update pipeline parameters](/api-reference/pipelines/update-pipeline-parameters) API.

A parameter of type SQL expression needs its own single quotes around text. Inside a single-quoted shell command, write each quote as `'\''`:

```bash
"parameters": {"run_date": "'\''2026-01-01'\''"}
```
