---
title: Function mapping to BigQuery SQL
description: List of supported Informatica functions and how they map to Prophecy functions in BigQuery SQL
---

While transpiling Informatica workflows to Prophecy pipelines, Transpiler converts Informatica functions into equivalent BigQuery SQL functions.

The following tables list all the Informatica functions that Prophecy supports and the corresponding Prophecy function it maps to in BigQuery SQL.

## Aggregate

| Informatica Function     | Equivalent Prophecy Function                                                       | Notes                                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `AVG`                    | `avg`                                                                              | Direct mapping                                                                                                            |
| `COUNT DISTINCT`         | `COUNT(DISTINCT col)` or `APPROX_COUNT_DISTINCT(col)`                              | Use `APPROX_COUNT_DISTINCT` for faster approx.                                                                            |
| `COUNT`                  | `count`                                                                            | Direct mapping                                                                                                            |
| `FIRST`                  | `any_value`                                                                        | Not deterministic. For deterministic “first by sort key”: `ARRAY_AGG(col ORDER BY sort_col ASC)[OFFSET(0)]`               |
| `LAST`                   | `any_value`                                                                        | Not deterministic. For deterministic “last by sort key”: `ARRAY_AGG(col ORDER BY sort_col DESC)[OFFSET(0)]`.              |
| `MAX`                    | `max`                                                                              | Direct mapping                                                                                                            |
| `MEDIAN`                 | `PERCENTILE_CONT(col, 0.5)` (analytic) or `APPROX_QUANTILES(col, 100)[OFFSET(50)]` | `PERCENTILE_CONT` is exact but analytic (use `PARTITION BY grp`); `APPROX_QUANTILES` gives a practical grouped aggregate. |
| `MIN`                    | `min`                                                                              | Direct mapping                                                                                                            |
| `STDDEV` / `STDDEV_SAMP` | `STDDEV_SAMP(col)`                                                                 | Sample std dev.                                                                                                           |
| `STDDEV_POP`             | `STDDEV_POP(col)`                                                                  | Population std dev.                                                                                                       |
| `SUM`                    | `SUM(col)`                                                                         | Direct mapping                                                                                                            |
| `VARIANCE` / `VAR_SAMP`  | `VAR_SAMP(col)`                                                                    | Sample variance.                                                                                                          |
| `VAR_POP`                | `VAR_POP(col)`                                                                     | Population variance.                                                                                                      |

## Conversion

| Informatica Function | Equivalent Prophecy Function |
| -------------------- | ---------------------------- |
| `TO_CHAR`            | cast `x` as `string`         |
| `TO_DATE`            | `date`                       |
| `TO_DECIMAL`         | cast `x` as `decimal(19,0)`  |
| `TO_FLOAT`           | cast `x` as `float64`        |
| `TO_INTEGER`         | cast `x` as `int`            |
