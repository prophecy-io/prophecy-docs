The **[Alteryx Download tool](https://help.alteryx.com/current/en/designer/tools/developer/download-tool.html?utm_source=chatgpt.com)** retrieves data from a URL or web endpoint and makes the response available to downstream tools in a workflow. It is commonly used to call REST APIs, fetch web-hosted files, or retrieve dynamically constructed URLs based on incoming fields.

In Prophecy, the closest functional equivalent is the **RestAPI** gem. This gem enables pipelines to issue HTTP requests, pass headers and parameters, authenticate against external services, and ingest API responses directly into a dataset for further transformation.

## Automated migration results

When Import encounters an Alteryx workflow that uses the Download tool to retrieve data from an HTTP or HTTPS endpoint, it maps this behavior to a **RestAPI** gem.

In typical migrations:

- The endpoint URL is transferred to the RestAPI gem’s URL configuration.
- The HTTP method (such as GET or POST) is inferred from the Download tool setup.
- Headers, query parameters, and request bodies are carried over when they can be statically determined.
- The API response is exposed as structured output when the response format is recognizable.

Because the Alteryx Download tool is highly flexible—and often relies on dynamically constructed URLs or headers—not all configurations can be migrated automatically without review.

## Manually replicate in Prophecy

To reproduce Download tool behavior manually:

1. Add a **RestAPI** gem to the canvas.
2. Configure the **URL** to point to the target endpoint.
3. Select the appropriate **HTTP method** (for example, GET or POST).
4. Define **headers** and **query parameters** as needed to match the original request.
5. Configure **authentication** if required by the endpoint.
6. Enable response parsing if the API returns structured data such as JSON.
7. Optionally connect an upstream dataset if the API call should be executed once per input row (for example, when URLs are constructed dynamically).

## Configuration options

### Endpoint and request method

- **Alteryx:** The Download tool allows arbitrary URLs and supports custom request construction through headers and payload configuration.
- **Prophecy:** The RestAPI gem separates these concerns into explicit fields for URL, HTTP method, headers, parameters, and body content.

This configuration reproduces the core behavior of the Alteryx Download tool within a Prophecy pipeline.

##

| Platform | Option                 | Description                            |
| -------- | ---------------------- | -------------------------------------- |
| Alteryx  | URL                    | Endpoint from which data is retrieved  |
| Alteryx  | Headers / Request body | Controls request metadata and payload  |
| Alteryx  | Incoming fields        | Used to dynamically construct requests |
| Prophecy | URL                    | Target API endpoint                    |
| Prophecy | Method                 | HTTP verb used for the request         |
| Prophecy | Headers / Params       | Request metadata and query parameters  |
| Prophecy | Authentication         | Controls how the request is authorized |

## Output behavior

- **Alteryx:** The Download tool outputs the raw response content, which is typically parsed by downstream tools.
- **Prophecy:** The RestAPI gem outputs rows representing the API response, optionally parsed into structured columns when the response format supports it.

## Known caveats

- **Dynamic logic:** Download tool configurations that rely heavily on formula-based URL construction may require manual adjustment in Prophecy.
- **Non-JSON responses:** APIs that return binary, CSV, or XML data may need additional handling downstream.
- **Execution semantics:** Per-row API calls can have performance and rate-limiting implications and should be reviewed carefully during migration.
