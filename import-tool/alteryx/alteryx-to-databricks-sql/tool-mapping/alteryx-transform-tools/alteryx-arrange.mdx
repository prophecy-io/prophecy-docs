Alteryx's [Arrange tool](https://help.alteryx.com/current/en/designer/tools/transform/arrange-tool.html) expands columns into rows for reporting, charting, or analytics purposes, adding descriptions to new rows.

Prophecy implements this functionality using multiple [Reformat gems](/data-analysis/gems/prepare/reformat).


Sample input:

| RecordID | start_date | end_date   | cancel_date | user  |
| -------: | ---------- | ---------- | ----------- | ----- |
|        1 | 10/14/2025 | 11/14/2025 | 12/14/2025  | Amy |
|        2 | 10/08/2025 | 11/08/2025 | 12/08/2025  | Walter |

Sample output:

| Description | Date        | RecordID | user  |
| ----------- | ---------- | -------- | ----- |
| Start date  | 10/14/2025 | 1        | Amy |
| End date    | 11/14/2025 | 1        | Amy |
| Cancel date | 12/14/2025 | 1        | Amy |
| Start date  | 10/08/2025 | 2        | Walter |
| End date    | 11/08/2025 | 2        | Walter |
| Cancel date | 12/08/2025 | 2        | Walter |


## Automated migration results

When Import detects an Alteryx Arrange tool, it generates a sequence of Reformat gems to reproduce row-expansion behavior:

- An initial Reformat gem creates an array of labeled row objects using `array` and `named_struct`. Each struct represents one output row derived from the original input row.

- A second Reformat gem applies `explode` to the array, converting each struct into its own output row.

- A final Reformat gem extracts fields from the exploded struct into standard output columns.

This approach mirrors the Arrange tool's “columns to rows” behavior using SQL-native constructs.

## Configuration options

To reproduce Arrange behavior manually:

1. Add a **Reformat** gem to construct an array of row objects.
2. Add a second **Reformat** gem that applies `EXPLODE` to that array.
3. Add a final **Reformat** gem to select fields from the exploded struct as output columns.

This sequence converts multiple input columns into multiple output rows while preserving row-level context.

### In Alteryx (Arrange tool)

Configure the tool by:

- Selecting the input fields to arrange
- Defining how fields are grouped or labeled
- Specifying whether other fields are carried through unchanged

The output is a row-expanded dataset where each arranged field produces a new row.

### In Prophecy (Reformat gems)

Configuration is expressed through column expressions:

- **Construct row objects** using `array` and `named_struct`
- **Expand rows** using `explode`
- **Extract fields** from the exploded struct into final columns

Example construction pattern:

```sql
ARRAY(
  NAMED_STRUCT('x', CAST(X1 AS string), 'Description', 'Start'),
  NAMED_STRUCT('x', CAST(X2 AS string), 'Description', 'End')
)
```

Row expansion:

```sql
EXPLODE(_consolidated_data_col)
```

Field extraction:

```
description = _exploded_data_col.Description
x           = _exploded_data_col.X
```

## Output behavior

- Alteryx outputs multiple rows per input row, with labels indicating the source field.
- Prophecy produces the same row expansion by exploding an array of structs, then emitting standard columns.

Row counts increase according to the number of arranged fields.

## Known caveats

- **Multiple-step implementation:** Arrange behavior is expressed across several Reformat gems rather than a single tool.
- **Type normalization:** Import may cast values (for example, to `string`) to ensure consistent struct schemas.
- **Intermediate columns:** Temporary columns (such as `_consolidated_data_col` and `_exploded_data_col`) are used internally and removed in the final output.

## Example

### Input dataset (before Arrange)

Assume the input dataset contains one row per record, with multiple date fields stored in separate columns:

| record_id | start_date | end_date   | cancel_date | user_name |
| --------- | ---------- | ---------- | ----------- | --------- |
| 1         | 10/14/2025 | 11/14/2025 | 12/14/2025  | Amy       |
| 2         | 10/08/2025 | 11/08/2025 | 12/08/2025  | Priya     |

### Alteryx Arrange tool

Goal: Convert the three date columns (`start_date`, `end_date`, `cancel_date`) into rows, with a descriptive label indicating the source of each date, while carrying through `record_id` and `user_name`.

#### Resulting output (after Arrange)

The Arrange tool produces a “long” dataset where each input row generates multiple output rows:

| description | date_value | record_id | user_name |
| ----------- | ---------- | --------- | --------- |
| Start date  | 10/14/2025 | 1         | Amy       |
| End date    | 11/14/2025 | 1         | Amy       |
| Cancel date | 12/14/2025 | 1         | Amy       |
| Start date  | 10/08/2025 | 2         | Priya     |
| End date    | 11/08/2025 | 2         | Priya     |
| Cancel date | 12/08/2025 | 2         | Priya     |

### Prophecy equivalent

In Prophecy, this shape is produced by:

1. Constructing labeled row values from the original columns
2. Expanding those values into multiple rows
3. Emitting standard output columns (`description`, `date_value`) alongside the carried-through fields

The end result matches the Arrange tool’s behavior: multiple labeled rows per original record, suitable for filtering, aggregation, or reporting.
