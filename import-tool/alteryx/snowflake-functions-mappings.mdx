---
title: Alteryx Functions Mappings to Snowflake SQL
description: List of supported Alteryx functions and how they map to Snowflake SQL
---

While transpiling Alteryx workflows to Prophecy pipelines, Transpiler converts Alteryx functions into equivalent SQL functions.

The following table lists all the Alteryx functions that Prophecy supports and the corresponding Prophecy function it maps to in a SQL project. Select the tab corresponding to the fabric you're using.

## Conditional

| Alteryx Function                             | Equivalent Prophecy Function                                                                                            |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `IF c THEN t ELSE f ENDIF`                   | `CASE WHEN THEN ELSE END`                                                                                               |
| `IF c THEN t ELSEIF c2 THEN t2 ELSE f ENDIF` | `CASE WHEN c THEN t WHEN c2 THEN t2 ELSE f END`                                                                         |
| `IIF`                                        | `CASE WHEN c THEN t ELSE f END`                                                                                         |
| `Switch`                                     | `CASE WHEN c THEN t WHEN c2 THEN t2 ... END` <br />The `...` symbolizes all the `WHEN c THEN t` statements you may have. |
