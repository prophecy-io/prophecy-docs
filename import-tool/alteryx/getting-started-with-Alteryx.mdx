With Prophecy's Import feature, you can migrate your data integration stack from Alteryx into Prophecy programmatically. When you import Alteryx files, Prophecy converts your existing workflows into low-code visuals and optimized open-source code.

This document describes the process of importing Alteryx files into Prophecy.

## Prerequisites

- Exported Alteryx workflows
- Databricks Fabric
- GitHub Account (recommended)

If you don't have an existing Prophecy Fabric and Prophecy Project, see [this guide](/data-analysis/environment/fabrics/create-fabric) for fabrics and [this guide](/data-analysis/development/projects/create-project) for setting up a project.

## 1. Export Alteryx Files

To begin, export your a workflow from Alteryx. See [Alteryx's Workflow Management page](https://help.alteryx.com/current/en/designer/workflows/workflow-management.html#workflow-management) for details on exporting.

During import, Prophecy can process either of the following file types:

- ** YXMD files ** : YXMD files contain information about the workflow components used and the connections between them. It also contains parameters, macros, and other metadata associated with the workflow. Example:

  ![YXMD File](/import-tool/alteryx/img/yxmc_file.png)

- **YXMC files** : YXMC files packages macros, which are reusable components or workflows created in Alteryx. A macro can be a collection of tools and configurations that perform a specific function or set of tasks. Example:

  ![YXMC File](/import-tool/alteryx/img/yxmc_file.png)

Once you have exported your Alteryx files, you are ready to import your Alteryx workflow into Prophecy.

## 2. Import Aleryx files as a bundle

To import a bundle into Prophecy:

1. Log in to Prophecy.
1. Click the **Import** button in the left sidebar.
1. In the page that opens, click **Import Bundle**.
   The **Select Source Type** page opens.
1. Click **Alteryx** to select it.

![source_page](/import-tool/alteryx/img/alteryx_source_page.png)

### 3. Enter Bundle Details

Next, enter bundle details:

1. Enter a name for the bundle (1). You can reference the bundle by name later.
1. Select the language for the bundle (2), such as _SQL_. Prophecy will generate open-source code in this language.
1. Select the team that will use the bundle (3). You can add more teams later.
1. Choose or create the **project** for the Prophecy workflow (4).
1. Select the **Fabric** where the workflow will run, such as Databricks (6).

![Bundle details](/import-tool/alteryx/img/alteryx_package_details.png)

A bundle stores imported artifacts, such as Alteryx files and pipelines for future reference.

To create a bundle:

1. Enter a name for the bundle.
1. Select a language for import (Spark/Python, Spark/Scala, or SQL). Prophecy will convert your imported Alteryx files to this language.
1. Select the [team](/data-analysis/administration/management/teams/teams) who will access the bundle. (You can add more teams later.)
1. Choose the [project](/data-analysis/collaboration/project-sharing) for the new workflow.
1. Select the Git branch where code will be stored. For more information on how Prophecy uses Git, see [Using Git with Prophecy](/data-engineering/ci-cd/git/git).
1. Select a [Fabric](/data-analysis/environment/fabrics/prophecy-fabrics) where the workflow will run. A fabric specifies everything required for execution, most importantly a connection to compute.

### 4. Upload Artifacts

In the page that opens, browse to open or drag-and-drop the Alteryx files that you created above.

Click **Next**.

![Upload Artifacts](/import-tool/alteryx/img/upload_alteryx_artifact.png)

Upload the Alteryx files that you want to transpile and click **Next**.

![Entity Page](/import-tool/alteryx/img/alteryx_entity_page.png)

Select the `.yxmd` file(s) for import. The Alteryx workflow will be converted to a [Prophecy Pipeline](/data-engineering/development/pipelines/pipelines).

![Add pipeline](/import-tool/alteryx/img/alteryx_add_pipeline.png)

Prophecy will assign default names for pipelines. You can edit these names if desired.

## 5. Analyze, validate and transpile

Prophecy lets you analyze and validate files before import.

To analyze files, click **Analyze**. Prophecy displays a report indicating the artifacts to be imported. To analyze your import, click **Analyze**.

Once you have reviewed the **Analyze** report, proceed with import:

1. Click **Validate**. You must validate files in order to proceed.
1. Click **Transpile**.

   The page that opens displays information on the import's progress. Simple workflows may finish importing in a few seconds, but complex workflows may take several minutes.

1. Once import completes, click **Import**.

   If desired, deselect any artifacts that you don't want to import.

## 6. View bundle overview

In the modal that opens, click **View Bundle Details**.

The page that opens displays entities that have been created in Prophecy: gems, pipelines, tables, jobs, and functions.

If Import was not able to read any Alteryx component, these are displayed as **Failed**.

(3) shows the overall transpiler coverage %.

![Package Overview](/import-tool/alteryx/img/alteryx_package_overview.png)

## 7. View imported pipeline

![Pipeline](/import-tool/alteryx/img/alteryx_open_pipeline.png)

To view and edit pipelines generated during import:

1. Click **Pipelines**.
1. Hover over the pipeline you wish to view and click the **Edit** icon (the pencil).

![Pipeline canvas](/import-tool/alteryx/img/alteryx_pipeline_canvas.png)

The Alteryx workflow has been converted into a pipeline. Confirm that all Alteryx components and functions have be mapped to equivalent Prophecy entities.

![Pipeline code](/import-tool/alteryx/img/alteryx_pipeline_code.png)

Prophecy has also generated optimal high-performance open source Spark code for you.

## 8. Run Pipeline

![Pipeline fabric](/import-tool/alteryx/img/alteryx_pipeline_fabric.png)

To run the pipeline, you need to attach a fabric cluster. To do so, click the **Attach a cluster** button in the upper right of Prophecy's visual canvas.

Once you attach a fabric, you can connect the sources from your Alteryx environment.

![Pipeline fabric](/import-tool/alteryx/img/alteryx_pipeline_fabric.png)

![Source filepath](/import-tool/alteryx/img/alteryx_source_path.png)

1. Click a Source gem.
1. Choose the file type from where you will read the data. This example reads from a CSV file stored in Databricks.
1. Provide the file location that points to the correct file in Databricks.
1. Click **Properties → Infer Schema** and verify whether the schema of the data is correct.
1. Click on the **Preview → Load** to preview the data read by the component. This lets you confirm that you have connected to the correct source.
1. Click **Save**.

Repeat these steps to change the file paths for all source and target components in your pipeline.

<Note>A **Target** gem contains information on a target storage location.</Note>

![Run Pipeline](/import-tool/alteryx/img/alteryx_run_pipeline.png)

To run the pipeline, click the **Run** button.

![Interim Data](/import-tool/alteryx/img/alteryx_interim_data.png)

After the pipeline runs successfully, you can data at each stage by clicking the **interim** icon.
